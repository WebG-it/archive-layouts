## Description

**Archive Layouts for YOOtheme** lets you design the Joomla **Archived Articles** page with the **YOOtheme Pro builder**, the same way you design category and featured pages. It needs YOOtheme Pro 5.

### Features

- A new YOOtheme template type, **Archived Articles**, for the menu item *Articles > Archived Articles*. It can be assigned by category (with child categories), page number and language.
- A dynamic content group, **Archive**: the archived articles of the page with every article field and all custom fields, a single article, and archive information (count, current page, filtered month and year, a ready-made filter form). It works with the YOOtheme Pagination element.
- Survives YOOtheme updates: nothing is written in the template folder.
- English and Italian. One-click updates through the Joomla Update System.

### Requirements

Joomla 5 or 6, PHP 8.1 or later, YOOtheme Pro 5. Tested on Joomla 6.2.0 and 5.4.10, PHP 8.4, YOOtheme Pro 5.0.51, together with Essentials for YOOtheme Pro and 4SEO.

This plugin only does the layout. The optional automation that keeps archived articles in one category is the separate plugin Auto Archive. YOOtheme Pro is a commercial product by YOOtheme and is not included.
